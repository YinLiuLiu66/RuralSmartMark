## 2. 固定演示数据

## 3. 现场演示路径

| 顺序 | 点哪里 | 看什么 |
|---|---|---|
| 1 | 打开主站，确认选中的是 `ZT-DEMO-001` | 6/6 完成、品牌护照、四站点状态、批次与卡车 |
| 2 | 拖动、缩放 3D | 低多边形是代码拼的程序化几何，不是外部 3D 模型；相机有阻尼 |
| 3 | 点右侧「包装设计」或 3D 包装站 | 切换「经典牛皮纸 / 山野红 / 夜绿」，3D 贴图同步；展示 IP 插画 |
| 4 | 点 3D 二维码立牌，或底部「溯源」 | 打开 `/trace/ZTDEMO26`：390px H5、四段审核章、价格公式与“演示测算”标注 |
| 5 | 在 H5 问守园人一个保守问题（如“怎么保存？”） | 回答有边界；认证/功效类问题会被拒答 |
| 6 | 回到主站 | 扫码数增加；同一浏览器会话只在首次打开 H5 时写入一次，重复打开不再 +1 |
| 7 | 打开右侧「总控」，问“现在到哪了” | 流式回复、思维链折叠；只有建档/通过/驳回/回退等写操作才出确认卡 |
