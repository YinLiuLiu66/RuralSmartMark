# PPT / 文案交接说明（答辩口径）

> 日期：2026-11-08
> 对象：负责 PPT 与对外文案的同学
> 起因：团队内部提出的七个问题（果农能干什么 / 提供什么服务 / B2B 还是 B2C / 能否网红带货 / B2B 怎么推广 / 是否做区域代理 / 怎么发展代理）
> 这七问本质是三个问题：**谁付钱、付钱买什么、怎么找到他们。**

---

## 0. 三句定调（所有页面都不许偏）

1. **客户是合作社 / 县域品牌主理人，不是散户果农。**
2. **卖的是「可审核、带出处、能交付」的品牌物料流水线，不是流量，不是带货。**
3. **现在是通过端到端验证的演示系统 + 已有生产部署方案，不是已上线 SaaS。**

写每一页之前先对一遍这三句。偏了就会被追问，且答不回来。

## 2. 可以写 / 不要写

### 可以写（有实现或文档支撑）

- 「AI 出初稿，人做判断」：每站都有人工审核门，可驳回、可写一句话重跑、可回退到早期站并作废下游。
- 「事实可机器校验」：知识库是唯一事实源，引用必须逐字命中；未认证、医疗功效、保证增收类表述硬拦截。
- 「定价数字不由模型生成」：服务端计算器算，模型只写解释，审核时再算一遍。
- 「一份物料多处同源」：同一张包装 PNG 同时用于 3D 盒贴图与溯源页，二维码指向同一批次。
- 「换产品不改代码」：换档案 + 知识库 + 包装模板 + 基准价四样即可；麻江蓝莓、平泉香菇已真实跑到 traced。
- 「一条能当场扫码的完整链路」：演示批次 `ZT-DEMO-001`，溯源码 `ZTDEMO26`。

### 不要写（写了就是编，且一追就崩）

- 带动多少农户、增收多少元、覆盖多少县域、帮多少合作社上架。
- 「已上线」「已服务 N 家客户」「签约」「合作单位」——目前没有。
- 「区域代理」「加盟」「招募合伙人」——明确不做。
- 「平台自带流量」「帮农户带货卖货」——不做交易撮合。
- 「替代设计师 / 替代运营团队」——它是初稿流水线，人是审核者。

## 3. 商业模式页建议结构（一页讲完）

三栏，从左到右读：

- **谁付钱**：合作社 / 县域品牌公司 / 产区服务商。不为散户果农做单人版。
- **买什么**：按批次交付的品牌物料包（故事 IP、包装文件、渠道内容、定价与溯源码）。
- **不做什么**：不代运营、不发货、不上架电商、不做达人佣金结算、不做加盟代理。

底部一行小字：*当前为端到端演示系统，生产部署方案见 docs/deploy.md；收入模型为待验证假设。*

---

## 4. 推广路径页建议结构（一页，标「待验证」）

按落地成本从低到高排：

1. **已有案例**：昭通丑苹果一个完整批次，现场可扫码（成本最低，先做）。
2. **县域组织**：地理标志协会、县级农业农村局、供销社——手里有合作社名单。
3. **反向渠道**：包装厂 / 印刷厂，他们已有做礼盒的合作社客户。
4. **换数据**：前 2–3 个批次免费或成本价，换真实数据（扫码数、审核修改率、实际上架价）。

页脚必须加：*以上为假设路径，尚未进行市场验证。*

## 5. 现场追问的一句话答法

- **「这不就是个大模型套壳吗」** → 模型只负责写；状态机、审核门、事实校验、定价重算、回退作废在模型外面，聊天机器人没有这些。
- **「果农自己会用吗」** → 不用，操作者是合作社运营者；果农是溢价受益方。
- **「能帮农民多赚钱吗」** → 逻辑是让溢价环节尽量留在产地；具体增收数字我们没有实测，不承诺。
- **「怎么和 Canva / 剪映比」** → 它们做单个物料；我们做的是同一批次从故事到溯源码的连续链路，且事实有出处。
- **「别人抄你怎么办」** → 抄代码容易，抄知识库和档案难；壁垒在县域事实的整理与校验，不在界面。

## 6. 一句话收尾（可用作 PPT 结尾页）

> 让一个县域农产品批次，从地头价走到品牌价——四个 Agent 在沙盘上完成故事、包装、内容、定价与溯源，每一步都有人签字，每一句都有出处。
