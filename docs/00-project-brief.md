# 00 · 项目概览（Project Brief）

> 状态：🔶 草案 — 产品方向已明确，部分细节待定
> 更新时间：2026-10-14

## 1. 一句话定位

**面向县域农产品的「AI 品牌化 + 3D 数字孪生供应链」演示平台**：
用 AI Agent 矩阵为土特产生成文化 IP 与营销内容，用游戏化的 3D 沙盘让合作社"像玩模拟城市一样"管理供应链，最终通过扫码溯源把品牌故事传递给消费者。

## 2. 背景与灵感来源

- **WareTrack Demo**（2026-10 爆火的仓库管理概念演示）：把工业 WMS 做成等距 3D 数字孪生——低多边形场景、可旋转缩放、点击任意物体弹出详情卡、状态实时演进。证明"工业软件不必长得像工业软件"。
- **「乡土印记」思路**：县域农产品的出路是"从卖产品到卖文化"——打造 IP + 文创，提升溢价。
- **融合命题**：用工业 4.0 级的供应链透明度，赋能最基层的农业（参赛叙事：**文化溢价 + 数字平权 双轮驱动**）。

## 3. 核心用户与场景

| 用户 | 场景 |
| --- | --- |
| 合作社 / 农户 | 在 3D 沙盘上看懂库存、车辆、订单；用 Agent 生成品牌故事与包装 |
| 运营方（平台侧） | 审阅 / 润色 AI 产出物；指挥多站点调度 |
| 消费者 | 扫礼盒二维码，看溯源全程、读 IP 品牌故事 |

## 4. 产品结构（四大块）

```
┌─────────────────────────────────────────────────────┐
│  ① 3D 沙盘主控台（等距视角数字孪生）                  │
│     站点/冷链车/托盘/运单 实时状态 + 环绕数据看板      │
├─────────────────────────────────────────────────────┤
│  ② Agent 工作台                                      │
│     五个 AI Agent 的任务流与产出物，人工润色闭环       │
├─────────────────────────────────────────────────────┤
│  ③ 扫码溯源 H5（消费者端）                            │
│     一物一码 → 溯源时间线 + IP 口吻品牌故事            │
├─────────────────────────────────────────────────────┤
│  ④ 模拟引擎（后端内核，用户不可见）                    │
│     虚拟时钟驱动的世界状态机，为 ①③ 供数据            │
└─────────────────────────────────────────────────────┘
```

## 5. 核心叙事（答辩主线）

1. **痛点**：农产品既缺"文化包装"（卖不上价），又缺现代供应链管理（损耗大、看不懂传统 WMS）。
2. **方案**：Agent 矩阵把数万元的设计/策划成本降到几百元；3D 沙盘把复杂供应链变成游戏沙盘。
3. **闭环**：Agent 生产的礼盒"入库"后变成沙盘里真实流动的托盘；沙盘记录的每段运输变成消费者扫码看到的溯源故事。**创意 → 物流 → 顾客** 全链路打通。
4. **数据**：目标溢价 50%+，用对比数据支撑（演示数据由模拟引擎按剧本生成）。

## 6. 项目性质声明

本项目为**挑战杯竞赛项目**，当前阶段以"完整、可控、可演示"为第一优先级，
不追求真实生产环境的数据接入与高并发。
