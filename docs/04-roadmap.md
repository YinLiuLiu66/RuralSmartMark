## 0. 切分原则

- **先让整个系统能转起来，再往里填料**：先拼好全部零件的塑料框架，再逐个上色精修
- 以"答辩演示动线"为验收标准：**沙盘可看 → 详情卡可点 → Agent 可产出 → 润色可改 → 扫码可溯源**

## 1. 三层切法

### 🎯 MVP（核心叙事闭环最小实证，已按 decisions #16 重切）

验收动线：**沙盘可看 → 详情卡可点 → Agent 可产出 → 润色可改 → 扫码可溯源**

| 项 | 说明 |
| --- | --- |
| 基础设施 | compose 单 `db` 服务 + Alembic 首版迁移（含 trace_event） + JWT 双角色（可适度滑期） |

## 2. 里程碑（暂定顺序，日期待排）

### M0 · 风险探针（立即启动，不入正式里程碑序列）

- **R3F 探针**：1–2 天，1 人，产出可旋转等距场景小样（4 个方块 + 点击高亮 + 假数据联动）。成败直接决定 M3 排期（5 天 vs 10 天）与 3D 呈现野心。⚠️ 团队尚未确认 R3F 经验，此项为强制风险前置。

### M1–M7

1. **M1 · 地基**：compose 单 `db` 服务 + Alembic 首版迁移 + JWT
2. **M2 · 世界活了**：sim 引擎（时钟/状态机/剧本）+ WS 推送 + 变更落库
3. **M3 · 看得见**：R3F 沙盘吃 WS 数据 + 详情卡 + 相机交互
4. **M4 · 会说话**：LLM 封装 + Agent 1/3 跑通 + 工作台润色闭环
5. **M5 · 扫码闭环**：trace_code + 溯源 H5（原 M6 前移，紧接 Agent 产出，形成"Agent 故事出现在溯源页"演示高点）
6. **M6 · 会算账**：price_benchmark + 沙盘页内嵌溢价对照图
7. **M7 · 冲刺与包装**：独立看板、Agent 2、温度曲线 + 答辩剧本打磨 + 概念演示视频
