# 04 · 路线图（MVP 切分）

> 状态：🔶 草案 — 分层切法已明确，里程碑日期待排
> 更新时间：2026-10-14

## 0. 切分原则

- **先让整个系统能转起来，再往里填料**：先拼好全部零件的塑料框架，再逐个上色精修
- 以"答辩演示动线"为验收标准：**沙盘可看 → 详情卡可点 → Agent 可产出 → 润色可改 → 扫码可溯源**

## 1. 三层切法

### 🎯 MVP（必须，先让系统跑通）

| 项 | 说明 |
| --- | --- |
| 基础设施 | PostgreSQL（docker compose）+ Alembic + JWT 双角色 |
| 模拟引擎 | 虚拟时钟 + 六类实体状态机 + 可重放固定剧本 + WS 推送 |
| 3D 沙盘 | R3F 等距场景（程序化 low-poly）+ 详情卡 + 选中高亮 |
| Agent 1&3 | story 写故事 + marketing 写文案，产出入库 |
| 数据看板 | ECharts：库存/溢价/运单统计 |
| Agent 工作台 | 任务列表 + 产出物审阅/润色界面 |

### 🚀 冲刺（该有，夯实卖点）

| 项 | 说明 |
| --- | --- |
| Agent 2 画包装 | 接国内文生图 API，产出 IP 形象与包装图 |
| Agent 4 溯源页 | 扫码 H5：时间线 + IP 口吻文案（数据来自模拟引擎历史） |
| 溢价核算 | price_benchmark + 大屏溢价动效 |
| 模拟剧本打磨 | 答辩专属剧本：事件节奏与讲解词对齐 |

### 🎁 展示位（可伪，加分项）

| 项 | 说明 |
| --- | --- |
| Agent 5 调度建议 | 规则触发 + LLM 话术，地图上画路线（不做真优化求解） |
| 溯源页 AI 对话 | 顾客与 IP 角色聊天（缓存对话树优先，实时兜底） |
| 客舱温湿度动效 | 冷链车详情卡里的温度仪表动态演示 |

## 2. 里程碑（暂定顺序，日期待排）

1. **M1 · 地基**：compose 起 PG + Alembic 首版迁移 + JWT
2. **M2 · 世界活了**：sim 引擎（时钟/状态机/剧本）+ WS 推送 + 变更落库
3. **M3 · 看得见**：R3F 沙盘吃 WS 数据 + 详情卡 + 相机交互
4. **M4 · 会说话**：LLM 封装 + Agent 1/3 跑通 + 工作台润色闭环
5. **M5 · 会算账**：溢价对照 + 看板动效
6. **M6 · 扫码闭环**：trace_code + 溯源 H5
7. **M7 · 冲刺与包装**：Agent 2/5 + 答辩剧本打磨 + 概念演示视频
