# Bundled fonts

- Noto Serif SC Regular/Bold
- Noto Sans SC Regular/Bold

Source: [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk), `Serif/SubsetOTF/SC/` and `Sans/SubsetOTF/SC/`.
Downloaded: 2026-10-22.
License: SIL Open Font License 1.1; see `OFL.txt`.

These are the official Simplified Chinese OTF subsets (full SC character set, not a
small hand-picked glyph subset). They are bundled so Pillow can render packaging PNGs
on machines without macOS fonts.
